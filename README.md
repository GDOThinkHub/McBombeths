# Mc Bombeth's Flower Shop — Online Store (Demo)

Online store prototype for **Mc Bombeth's Flower Shop**, Alba's Building, Public Market, San Jose, Balanga City, Bataan.

- Single-file website: `index.html` (images embedded, no build step)
- Product catalog, size options, add-ons, cart, checkout
- Mock payments: GCash, Maya, card, bank transfer, PayPal, over-the-counter

> Demo only: prices are sample prices pending confirmation from the shop, and all payments are simulated.

To view it live, enable **GitHub Pages** (Settings → Pages → Deploy from branch `main`, folder `/root`).
